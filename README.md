# Sales Performance Dashboard

## 📊 Project Overview

An interactive Sales Performance Dashboard created using Tableau
to analyze sales, profit, products, categories, regions, and segments.

## 🛠️ Tools Used

- Tableau
- Excel / Superstore Dataset

## 📌 Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Average Discount KPI
- Sales by Month
- Sales by Category
- Profit by Region
- Sales by Segment
- Top 10 Products
